# Q-002F Contract Tests v2

This is the frozen BCL-only suite for the compiled Q-002F fence-only derivative. It supersedes the incompatible v1 harness, whose API assumptions were based on a different fixture and did not compile against Q-002F.

The suite makes no change to the generated candidate. It tests eight contract clauses using Q-002F's actual public signatures: enum shape, blank idempotency-key rejection, metadata-order invariance, full normalized URI fingerprinting, string fingerprint immutability, UTC/positive lease validation, distinct claim token, and terminal lease clearing.

Run only through the temporary short mapped drive and preserve the full console output. This is a human-plus-model derivative measurement and does not revise Q-002's autonomous failure.
